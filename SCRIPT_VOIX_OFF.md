# Sunu École — Script voix-off 60 secondes

> **Usage :** Collez ce script dans ElevenLabs / Play.ht / votre studio d'enregistrement.  
> Voix conseillée : masculine ou féminine, 30-40 ans, posée, chaleureuse, professionnelle — accent sénégalais léger accepté.  
> Débit : ~145 mots/minute. Musique : Afro-lofi discrète + léger pad corporate (voir notes).

---

### 0:00 – 0:06 — INTRO
> *Musique monte doucement, hit subtil à 0:02*
> 
> **« Et si vous pilotiez votre école entière… dans une seule plateforme ? »**
> 
> *Pause 0.4s*
>
> **« Sunu École. La plateforme scolaire pensée pour les directeurs du Sénégal. »**

**À l'écran :** Logo Sunu École, mock dashboard direction animé, KPI qui comptent (248 élèves, 96% paiement), badge « Sans abonnement mensuel ».

## Notes musique & sound design

- **0:00-0:06** : Pad warm + léger kora/pluck sénégalais, hit doux à l'apparition du logo
- **0:06-0:10** : Petit “woosh” quand les 3 cartes chaos se rassemblent
- **0:25-0:33** : “Pop” Mobile Money (son caisse), “ding” reçu imprimé
- **0:52-0:60** : Montée musicale, hit + reverb sur “Accès à vie”, fade out 1.5s
- **Durée totale** : 60.0s exactement — prévoir 0.8s de silence avant/après si export vidéo

## Export

- **Vidéo** : Enregistrez l'écran en 1920×1080, 60fps, **touche H** pour masquer l'interface, **F** pour plein écran, **Espace** pour pause/play
- **WhatsApp** : Générez aussi la version 9:16 (fichier `vertical.html` à venir) pour stories/status
- **PDF** : Imprimez le bulletin de démo depuis la plateforme pour montrer aux directeurs en physique
